# Enhancement roadmap

This project is intentionally built in stages. The current baseline is a local OA gait screening prototype. The next enhancement tasks are:

1. Standardize the camera capture protocol.
2. Add a binary screening mode alongside the four-class severity model.
3. Improve the movement feature engineering with gait timing and symmetry metrics.
4. Connect uploaded webcam/video inference to the app.
5. Add the X-ray module as a separate path using the KL-grade dataset.
6. Integrate explainability for the X-ray branch only after a reliable model is trained.

Key principle: movement, questionnaire, and X-ray results should remain visible and separate until a clinically validated fusion strategy is ready.
